# Synthetic Data Distillation for Turkish Abstractive News Summarization

Code, data caches and analysis for the IEEE paper *"Synthetic Data Distillation from Large
Language Models for Turkish Abstractive News Summarization"* (IDAP 2026, 10th International
Artificial Intelligence and Data Processing Symposium).

A 300M-parameter student (mT5-small + LoRA) is trained on ~10,000 summaries generated by a
commercial LLM teacher, then compared against zero-shot mT5-small, the same model supervised on
human references, and the teachers themselves — in-domain on MLSUM-TR and out-of-domain on
TR-News.

## Results

The distilled student recovers **92.6%** of its teacher's stemmed ROUGE-1 in-domain and
**significantly outperforms both teachers out of domain**, at roughly $15 of API spend and
14 hours of free-tier T4 time.

**MLSUM-TR test, 2,000 articles**

| --- | ---: | --- | ---: | ---: | ---: | ---: |
| B1 zero-shot mT5-small | 0.094 | [0.090, 0.099] | 0.114 | 0.851 | 0.018 | 0.27 |
| B2 human-supervised | 0.277 | [0.268, 0.286] | 0.315 | **0.891** | 0.004 | 0.70 |
| B3a GPT-4o-mini (teacher) | **0.278** | [0.273, 0.283] | **0.332** | 0.891 | 0.021 | 2.12 |
| B3b Claude Haiku 4.5 (teacher) | 0.276 | [0.270, 0.281] | 0.331 | 0.888 | 0.039 | 2.19 |

| S-claude (distilled) | 0.264 | [0.256, 0.272] | 0.305 | 0.887 | 0.004 | 0.94 |

| --- | ---: | --- | ---: | ---: | ---: | ---: |
| B2 human-supervised | **0.279** | [0.266, 0.292] | **0.325** | **0.893** | 0.002 | $+0.002$ |

S-gpt beats GPT-4o-mini by 2.1 ROUGE-1 points ($p=0.0015$) and Claude Haiku 4.5 by 1.9
($p=0.0024$), Holm-corrected paired randomization. The teachers are statistically **equivalent**
in-domain under a pre-registered $\pm 0.010$ margin (TOST, $p=7.6\times10^{-8}$).

### Faithfulness is a trade, not a win

The students fabricate numbers about five times less often than their teachers, but that figure
is **numeric-only and not length-normalised** — the teachers write 2.1–3.1× the reference length
and the students 0.7–1.4×, so a per-summary rate favours the shorter system. Identity and
attribution errors appear only in the distilled students. See §VII-B of the paper for what this
does and does not license.

### A decoding artifact we found in our own evaluation

mT5 is pretrained on span corruption alone, so its decoder emits `<extra_id_0>` at the start of
**every** sequence. Our released inference code now strips it; the earlier evaluation did not.
The artifact was fully systematic — exactly 1.000 sentinels per summary for every trained small
model, 1.072 for untrained B1, zero for the API teachers.

Because our ROUGE tokenizer removes only `<` and `>`, `extra_id_0` survived as a word token.
Re-scoring on stripped output leaves ROUGE **recall unchanged to four decimals** for every system
while raising precision by 1.4–2.9 points and BERTScore by 1.6–2.6. Scoring the archived
predictions reproduces every number in the submitted version to three decimals, so the deltas are
attributable to the artifact alone. Verification: decoding 200 articles twice from the same
checkpoint, the post-hoc regular expression reproduced the in-pipeline strip on **198 of 198** rows.

```bash
python -m src.eval.clean_predictions --in-dir outputs/predictions/v1_raw \
    --out-dir outputs/predictions/clean --stats-json outputs/results/v2/sentinel_incidence.json
python scripts/artifact_impact.py --dirty ... --clean ...   # the before/after table
```

## Reproducing the published numbers

From the released predictions, no GPU and no API keys required:

```bash
python -m src.eval.run_eval_v2 \
    --pred B1=outputs/predictions/clean/B1_zeroshot.jsonl \
    --pred B2=outputs/predictions/clean/B2_human.jsonl \
    --pred B3a=outputs/predictions/clean/B3a_gpt.jsonl \
    --pred B3b=outputs/predictions/clean/B3b_claude.jsonl \
    --pred S-gpt=outputs/predictions/clean/S_gpt.jsonl \
    --pred S-claude=outputs/predictions/clean/S_claude.jsonl \
    --metrics rouge errors bertscore \
    --per-example-dir outputs/results/v2/per_example_clean_main \
    --out-json outputs/results/v2/main_eval_CLEAN.json

python -m src.eval.pairwise_stats \
    --per-example-dir outputs/results/v2/per_example_clean_main \
    --metric standard_rouge1_f --delta 0.010
```

`src/eval/stats.py` carries a self-test: `python src/eval/stats.py`.

## Statistical protocol

Pre-registered in [`PREREGISTRATION.md`](PREREGISTRATION.md) before the analysis was run:
primary outcome, equivalence margin, seed plan and judge-exclusion rule.

- 95% BCa bootstrap confidence intervals, 10,000 resamples
- paired approximate randomization tests with Holm–Bonferroni correction
- TOST equivalence testing at $\delta = 0.010$ ROUGE-1

These cover test-set sampling uncertainty only. **Every trained system is a single run at seed
42**; training-seed variance is not estimated. A three-seed protocol is implemented
(`scripts/05_multiseed.py`) but was not executed before the camera-ready deadline.

## Bias and ethics analysis

Post-hoc, no retraining, no GPU, no API key:

```bash
python -m src.eval.bias_analysis --self-test
python -m src.eval.bias_analysis --pred B1=... --source data/raw/mlsum_tr/test.jsonl \
    --out-json outputs/results/bias_results.json --fig-dir report/figures
```

MLSUM-TR is male-skewed (24.4% of gendered mentions are female). The verbose teachers preserve
that ratio; every compressive system, including the human-supervised baseline, drops to
20–21% — compression, not distillation, drives the skew. Student weights are **not** released,
given the synthetic-news misuse risk and the elevated misattribution rate.

## Known limitations

Stated plainly, because they bound what the results mean:

- **Single training run.** Seed 42 only; the intervals do not cover training noise.
- **The LLM judge is not independent.** Claude Opus judged outputs from a Claude teacher,
  unblinded, seeing only the first 600 characters of the source article.
- **Faithfulness is measured on numbers only** and is confounded with summary length.
- **Omission is partly architectural.** The 512-token input window covers the median MLSUM-TR
  article (1,159 characters) but not the tail (p95 4,061; max 26,612).

Protocols for all four are implemented and pre-registered here; they were not run in time.
